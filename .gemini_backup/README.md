# Gemini Conversation Backups

This folder contains backed-up Gemini/Antigravity AI conversation transcripts so you can continue work on any machine.

## Structure
```
.gemini_backup/
├── conversations/
│   └── <conversation-id>/
│       └── transcript.jsonl    # Full conversation log
└── README.md
```

## How to restore
1. Clone this repo on a new machine
2. Start a new Gemini conversation  
3. Share the transcript file with the AI to restore context
